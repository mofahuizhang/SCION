# SCION 可证伪实验方案

> **依据**：SCION v1.3 第七章可证伪条件（7 条）
> **目标**：把 7 条断言转为可执行实验，任一条件失败即对应断言降级或修正
> **复用资产**：探针实证本地模型（bert-base-chinese / chinese-roberta-wwm-ext / ernie-3.0-base-zh）+ SUI 金标（sui_gold_expert.json，含层累层数据）+ 命题登记表（概念库）
> **诚实声明**：SUI 金标为"蒸馏骨架产物，非最终真值"（cdc_distilled=false），层累链深度需人工核验后使用；本地 BERT 系为编码模型，生成式实验需 API
> **日期**：2026-08-26

---

## 一、实验矩阵总览

| 条件 | 断言 | 实验 | 核心度量 | 依赖 | 批次 |
|------|------|------|---------|------|------|
| P-1① | 杠杆与层累链深度正相关 | E-1 | 杠杆倍数 = 语义密度/提示词长度 | 金标层累链 + 双规模 API | 一 |
| P-1② | SUI 地址效率 > 结构化提示词 | E-2 | 生成质量/延迟/成本 | SUI 编译器 | 三（条件性） |
| P-1③ | 杠杆跨模型稳定 | E-3 | 杠杆倍数随模型规模单调 | 本地 BERT + API | 一 |
| P-1④ | 压缩来自起点上移非 token 减少 | E-4a | 同 token 数下压缩比差异 | API | 二 |
| P-2 | 压缩比 ∝ 层累链深度 × 分支因子 | E-4b | 压缩比与深度×分支因子相关 | API | 二 |
| ⑥ | 类代码提示词解析确定性更高 | E-5 | 输出语义一致性 | 本地 BERT | 二 |
| ⑦ | 语义种子包跨模型迁移 > 随机基线 | E-6 | 迁移成功率 | 本地模型 + API | 一 |

## 二、实验设计

### E-1 认知杠杆与层累链深度（P-1 条件 1）

**假设 H1**：杠杆倍数与概念层累链深度正相关——深链概念（≥3 层）的提示词杠杆显著高于浅链概念（≤2 层）。

**设计**：
- 概念样本：从 SUI 金标 + 命题登记表选取 10 个深链概念（如"道/德/气/仁/礼"等，层累链 ≥3 层）与 10 个浅链概念（≤2 层）；层累链深度由人工核验金标层累数据后标注（金标为骨架产物，深度值需确认）
- 提示词变体：每概念 3 个提示词变体（描述式/角色式/锚点式），长度归一（token 数控制在 ±10%）
- 模型：两个参数量级（如 7B 与 70B 级 API）
- 重复：3 次/组合 → 20 概念 × 3 变体 × 2 模型 × 3 次 = 360 次生成

**度量**：
- 提示词长度（token 数）
- 输出语义密度（义原覆盖率或嵌入向量范数，代理指标）
- 杠杆倍数 = 语义密度 / 提示词 token 数

**判定**：深组与浅组杠杆倍数无显著差异（独立样本 t 检验 p>0.05 或 Cohen's d<0.3）→ H1 证伪 → P-1 条件 1 失败。

### E-2 SUI 地址 vs 结构化提示词（P-1 条件 2）

**假设 H2**：同一任务下，SUI 地址（精确锚点）生成效率显著高于等价结构化提示词。

**设计**：
- 任务集：10 个标准任务（概念解释/对比/演绎）
- 输入形态：SUI 语义地址 / 等价结构化提示词（同任务、同目标节点）
- 度量：生成质量（专家评分 1-5）、延迟、token 成本

**判定**：SUI 地址组质量无显著提升且成本无下降 → H2 证伪 → P-1 条件 2 失败。

**状态**：条件性实验——依赖 SUI 编译器/地址生成工具可用。当前 SUI v6.4 有编译协议，编译器成熟度待确认；未就绪前标记 PENDING，不列入执行批次。

### E-3 跨模型杠杆稳定性（P-1 条件 3）

**假设 H3**：同一提示词在不同模型上杠杆倍数随参数空间密度单调递增（模型越大杠杆越高）。

**设计**：
- 提示词样本：10 个固定提示词（覆盖深/浅概念）
- 模型：4 档（本地 ernie-3.0-base-zh / chinese-roberta-wwm-ext / bert-base-chinese + 1 个 API 模型）
- 重复：3 次/组合 → 10 × 4 × 3 = 120 次

**度量**：杠杆倍数（同 E-1）；本地编码模型用"提示词→语义锁定强度"代理（输出向量与目标节点向量的对齐度），API 模型用生成杠杆。

**判定**：同一提示词跨模型杠杆倍数无法形成单调排序（秩相关 ρ<0.5）→ H3 证伪 → P-1 条件 3 失败。

### E-4 压缩来源分解（P-1 条件 4 + P-2 条件 5）

**假设 H4a**：token 数相同时，起点高（锁定高层节点）的提示词压缩比大于起点低（未锁定高层）的提示词。
**假设 H4b**：压缩比与层累链深度 × 分支因子正相关。

**设计**：
- 提示词对：10 对"起点高/起点低"变体，**token 数严格控制相等**（排除字数解释）
- 深度×分支因子：每概念量化（深度=层累链层数，分支因子=节点下行展开平均分支，人工标定）
- 模型：1 个 API 模型；重复 3 次 → 10 对 × 3 = 30 次对比
- 度量：压缩比 = 输出 token / 输入 token（或生成延迟）

**判定**：H4a 起点高组压缩比不优于起点低组（配对 t 检验 p>0.05）→ P-1 条件 4 证伪；H4b 压缩比与深度×分支因子相关性 r<0.3 → P-2 条件 5 证伪。

### E-5 类代码解析确定性（条件 6）

**假设 H5**：类代码提示词（结构化语法）比同语义自然语言提示词的解析确定性更高——多次运行输出更一致。

**设计**：
- 任务：10 个标准任务
- 形态：自然语言提示词 / 等价类代码提示词（同语义、同目标）
- 运行：5 次/组合，温度固定 → 10 × 2 × 5 = 100 次
- 度量：输出语义一致性——多次运行输出的嵌入余弦相似度均值（本地 BERT 编码）、语义簇离散度

**判定**：两形态输出一致性无显著差异（p>0.05）→ H5 证伪 → 条件 6 失败。

### E-6 语义种子包跨模型迁移（条件 7）

**假设 H6**：同一提示词在异构模型上能稳定锁定同一语义节点，迁移成功率显著高于随机基线。

**设计**：
- 提示词样本：15 个（深/浅概念混合）
- 模型：异构组合（本地 BERT 系 2 个 + API 模型 1 个，架构/厂商异质）
- 基线：15 个随机提示词的"锁定率"（随机提示词输出与目标节点对齐的比例）
- 度量：迁移成功率 = 提示词输出与目标节点语义对齐率（嵌入距离阈值判定，阈值用随机基线校准）

**判定**：迁移成功率 ≤ 随机基线（χ² 检验 p>0.05）→ H6 证伪 → 条件 7 失败（寻址结构不可归因，SCION 第五章产权基础动摇）。

## 三、执行批次规划

| 批次 | 实验 | 前置条件 | 说明 |
|------|------|---------|------|
| 第一批 | E-1 / E-3 / E-6 | API 可用 + 金标层累链人工核验 | 零工具依赖，先跑通测量框架 |
| 第二批 | E-4 / E-5 | 提示词变体构造工具 | 需先写变体生成脚本 |
| 第三批 | E-2 | SUI 编译器可用 | PENDING，条件性 |

## 四、诚实声明与边界

1. **金标限制**：SUI 金标为蒸馏骨架产物（cdc_distilled=false），层累链深度/分支因子需人工核验标定，核验前实验数据不视为最终结论
2. **模型限制**：本地 BERT 系为编码模型（无生成能力），E-3/E-5/E-6 的语义一致性测量可本地完成；E-1/E-4 的生成杠杆度量需生成式 API
3. **外部实证不依赖**：CHIP 30% 等外部数据（T-A1）不进入本方案判定，方案自建测量
4. **判定纪律**：任一实验失败即对应断言降级——不通过修改测量口径挽救断言；测量口径在实验前冻结
