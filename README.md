# SCION · 提示词寻址篇

> **SCION**（接穗，源自嫁接——砧木为根系，接穗定果实）。
>
> 定位：**面向大模型的外部语义控制层**——提示词在认知语义基元三论（CSMT/CCT）理论坐标系中的完整展开。

---

## 概述

大模型是一个庞然大物：数百亿参数，在万亿 token 上预训练。但每一轮对话都由几十到几百个字符的输入启动——提示词。这个输入与模型的体量完全不成比例，却决定性地塑造了输出。

**嫁接**提供了精确的模型：砧木（rootstock）= 大模型（参数空间与预训练分布），接穗（scion）= 提示词（外部锚点注入），接穗决定果实（输出语义定位）。

提示词的核心功能不是承载参数化知识，而是携带"结什么果"的指令——外部锚定、调度与约束。

### 四动作工作机制

| 动作 | 功能 | 理论锚点 |
|---|---|---|
| **锚定** | 锁定层累链节点 | D29 锁定 |
| **注入** | 接管追溯深度 k_prompt | T13a × M8 |
| **控制起点** | 上移生成起点 | L26 层级展开 |
| **约束展开** | 从节点下行展开 | D8 组合算子 |

### 四类锚点

| 锚点类型 | 功能 | 示例 |
|---|---|---|
| **内容锚点** | 锁定层累链节点（决定"说什么"） | "以老子的视角解释德" |
| **风格锚点** | 调制生成分布参数（决定"怎么说"） | 角色设定改变语气/采样偏好 |
| **识解锚点** | 调制解读视角（决定"以什么视角看"） | 框架激活→显著性控制→识解选择 |
| **复合锚点** | 多种锚点同时注入 | "大肥鱼"类角色心智引擎 |

## 核心理论

### 1. 存在性证明：提示词是组合复杂度的必然产物

- **锚点倒转阈值定理（D7）**：当组合复杂度超过阈值 N_th=3 时，概念的锚点从内部义原翻转到外部参考点
- **提示词锚定定理（T7）**：提示词 = 高复杂度概念注入外部锚点
- 提示词机制不是产品发明，而是公理链的推论

### 2. 量化维度

| 维度 | 公式 | 状态 |
|---|---|---|
| **认知杠杆（C9）** | Leverage = 层累链深度（跨模型稳定项）× 参数空间密度（模型相关项） | E-3 实证修正 |
| **压缩比（C10）** | Compression = 层累链深度 × 分支因子，上界 min(5×, 实际链深度×分支因子) | E-4 实测 15.1×（结构表示） |
| **锚定置信度（M6）** | 锁定节点明确程度、语境语义距离、概念稳定性 | 理论度量，待实测 |
| **追溯深度控制精度** | 实际展开深度与 k_prompt 偏差的倒数 | 概念度量，待实测 |

### 3. 演化路径

```
阶段一：自然语言提示词 → 阶段二：结构化提示词 → 阶段三：类代码提示词 → 阶段四：语义地址（SUI衔接点）
```

### 4. 压缩本质

提示词的压缩 = **展开起点上移**（P-2/C10/L26，上界5×）+ **寻址路径缩短**（D12，编码跳数减少）

压缩的不是字数，是跳数。

### 5. 新型交付物：语义种子包（SPORE）

提示词正在成为可复制、可传播、可交易的新型交付物。资产价值的锚点不是文字表达的独创性，而是**寻址路径唯一性**——同一节点可重复锁定 + 路径可测量。

## 与同源框架的关系

```
CART（认知注意力资源论）── 底层注意力预算与资源约束
    │
CCT（认知编码论）──────── 编码结构与语义寻址理论
    │
SCION（提示词寻址篇）──── 自然语言侧软路由（本项目）
    │
SUI（语义寻址语言）────── 形式化地址硬编码（独立篇章）
```

- **SCION 与 SUI**：硬编码与软路由关系——SCION 管自然语言侧语义锚定路由，SUI 管锚定后的形式化地址锁存
- **共享底座**：D29/T13a 公理底座，互不注册，各自独立演进
- **分工**：三论管"语义为什么可寻址"，SCION 管"自然语言如何寻址"，SUI 管"地址如何形式化"，大模型管"地址如何被展开"
