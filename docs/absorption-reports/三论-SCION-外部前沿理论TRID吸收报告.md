## 二、TRID 三关评估（新吗 / 真吗 / 用吗）

### T-1 识解锚点（语义控制论）——中等实质增量

- **新吗**：✅ 新。语义控制论的**识解选择（construal selection）**是 SCION 未明确覆盖的维度——同一节点可被不同识解（视角/解读方式）调制。SCION 有内容锚点（说什么）/风格锚点（怎么说），识解选择是"以什么视角解读"——第三种调制维度，且是语义控制论三级层次中最深的一级。
- **真吗**：✅ 论文实证（P0）。
- **用吗**：✅ SCION 第二章 2.1 锚点类型可补"**识解锚点**（视角调制——同一层累链节点的不同识解方式）"，与内容/风格锚点并列；语义控制论的三级层次（框架激活→显著性→识解）可与 SCION 四动作（锚定→注入→控制起点→约束展开）形成互补视角（前者认知语言学描述，后者形式机制）。

### T-2 内部信息流视角（搜索空间复杂性）——轻量增量

- **新吗**：✅ 视角互补。该理论从**模型内部信息流**（隐藏状态 h 的信息提取）分析提示词；SCION 从**外部语义锚定**出发。两者回答不同侧面：SCION 讲"锚定在哪"，该理论讲"锚定之后内部如何提取"。
- **真吗**：✅ ACL 2025（P1）。
- **用吗**：✅ SCION 第二章 2.4 展开机制可补一句内部视角引用（锚定后模型从隐藏状态选择性提取信息）；其"空间复杂度 = n × s"的乘法结构与 SCION 压缩比公式（深度 × 分支因子）同为乘法结构，可交叉印证。

### T-3 类代码工程佐证（lm-promptu / POML）——轻量增量

- **新吗**：✅ 工程佐证。SCION 第四章阶段三论述类代码属性的理论根据（S-A2 编码效率），但缺现实工程实现引用——lm-promptu（跨平台提示词 DSL）与 POML（HTML-like 结构化提示词框架）提供了现成佐证。
- **真吗**：✅ POML（Microsoft Research）与 lm-promptu（P1）。
- **用吗**：✅ SCION 第四章阶段三补一句工程佐证（类代码提示词已有现实工程实现：lm-promptu DSL / POML 结构化框架）。注意：POML 的"929% 准确率方差"是性能差异数据，非 SCION 机制证据，仅作工程存在性引用。

### T-4 PromptPrism 分类工具（操作化互补）——注记级

- **新吗**：✅ 工具互补。PromptPrism 是分类描述工具（三层：功能结构/语义组件/句法模式），SCION 是解释性理论——两者不冲突，可互补。
- **真吗**：✅ P0。
- **用吗**：✅ SCION 第四章阶段二补注记（结构化提示词可经 PromptPrism 分类法操作化分析——句法模式层与 SCION 的类代码演化描述互补）。

### T-5 自生成维度（EPA）——轻量增量 / 差异标注

- **新吗**：✅ 差异点。EPA 侧重**递归自生成**（输出成为下一输入，自组装架构）；SCION 孢子侧重**可传播可交易**（交付物）。"自生成/自演化"是 SCION 第六章未明确覆盖的种子侧面。
- **真吗**：✅ GitHub 项目（P1/P2，社区级——标注来源层级）。
- **用吗**：✅ SCION 第六章交付物补"自生长侧面"——语义种子包不仅可传播（孢子），还可迭代演化（版本化已覆盖，自组装是延伸维度）；同时标注与 EPA 的差异（SCION 关注交付物属性，EPA 关注自生成架构）。
