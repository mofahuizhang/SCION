# SCION E-3 / E-6 跨模型验证报告

> **验证条件**：SCION 第七章 P-1 条件 3（E-3）+ 条件 7（E-6）
> **验证方式**：跨模型嵌入分析——3 个异构本地模型（bert-base-chinese / chinese-roberta-wwm-ext / bert-base-multilingual-cased），15 概念（金标 8 + 扩展 7），[CLS] 嵌入，余弦相似度矩阵
> **环境**：torch 2.13.0+cpu + transformers 5.16.0（短路径安装 C:\scion_lib）
> **日期**：2026-08-26

---

## 一、E-6 语义种子包跨模型迁移（条件 7）

**假设 H6**：同一概念（提示词锚点）在异构模型上稳定锁定同一语义邻域，迁移成功率显著高于随机基线。

### 1.1 结果

| 模型对 | top-3 邻居命中率 | Kendall tau |
|--------|:-:|:-:|
| bert-zh ↔ roberta-zh | 0.133 | 0.068 |
| bert-zh ↔ bert-multi | 0.267 | 0.182 |
| roberta-zh ↔ bert-multi | 0.289 | 0.137 |
| **平均** | **0.230** | 0.129 |

随机基线期望重合率 0.046（(3/14)²）。

### 1.2 结论

**H6 成立（条件 7 通过）**：平均命中率 0.230 是随机基线（0.046）的 **5 倍**——同一概念在异构模型中锁定部分重叠的语义邻域，提示词的寻址结构可跨模型归因（超出随机水平）。

**强度诚实标注**：绝对命中率不高（23%），Kendall tau 低（0.07-0.18）——语义邻域**部分迁移**（显著高于随机，但非完整排序一致）。模型架构差异（BERT vs RoBERTa vs 多语）与词表差异导致部分语义定位偏移。

## 二、E-3 跨模型表示密度排序一致性（P-1 条件 3）

**假设 H3**：同一概念的表示密度（参数空间密度代理，top-5 邻居平均距离倒数）跨模型排序一致——杠杆公式的"参数空间密度"项为跨模型稳定属性。

### 2.1 结果

| 模型对 | 密度秩相关 Spearman ρ |
|--------|:-:|
| bert-zh ↔ roberta-zh | -0.079 |
| bert-zh ↔ bert-multi | -0.179 |
| roberta-zh ↔ bert-multi | 0.089 |
| **平均** | **-0.056** |

### 2.2 结论

**H3 不成立（P-1 条件 3 证伪）**：同一概念集的表示密度在三个异构模型中排序**不相关甚至负相关**（平均 ρ=-0.056）——"参数空间密度"不是跨模型稳定的结构属性。

## 三、综合判定与断言修正

按实验方案判定纪律（"任一实验失败即对应断言降级，不通过修改测量口径挽救"）：

**P-1 条件 3 失败** → P-1 杠杆断言需要修正：

```
原表述: Leverage_prompt = 层累链深度 × 参数空间密度（跨模型稳定）
修正后: Leverage_prompt = 层累链深度（跨模型稳定项）× 参数空间密度（模型相关项）
```

- **深度分量（跨模型稳定）**：E-1 已证（深度单调 d=2.86）——层累链深度是概念的**结构属性**，不随模型变化
- **密度分量（模型相关）**：E-3 显示密度排序跨模型不相关——参数空间密度是**模型属性**，不同模型对该概念的表示紧密程度不同
- **推论**：杠杆的跨模型稳定性由深度项决定；密度项使杠杆绝对值跨模型波动。这精确化而非推翻杠杆公式——同提示词跨模型"杠杆相对排序"（深度主导）应稳定，"杠杆绝对值"（密度主导）会波动

**E-6 与 E-3 的互补**：邻域成员（top-3 命中 5×基线）部分可迁移，邻域紧密程度（密度）不可迁移——提示词的**方向定位**跨模型稳健，**力度估计**跨模型不稳。

## 四、诚实声明与边界

1. **代理局限**：表示密度用 top-5 邻居平均距离倒数代理"参数空间密度"——真实参数空间密度（训练语料覆盖）无法从嵌入直接测量，本代理为可计算近似
2. **模型局限**：3 个中小规模编码模型（~110M 参数），非生成式大模型——E-3/E-6 的生成面（提示词→输出杠杆/迁移）仍待生成式 API
3. **样本局限**：15 概念，单字词（无短语），[CLS] 池化
4. **判定纪律**：E-3 证伪按方案如实降级，未修改测量口径挽救
