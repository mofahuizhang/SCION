# SCION E-4 结构性验证报告

> **验证条件**：SCION 第七章 P-1 条件 4 + P-2（结构版）——压缩来自起点上移（非 token 减少），压缩比与层累深度正相关
> **验证方式**：结构性验证（纯 Python）——概念锚点（节点层表示）vs 完整定义（义原层展开）的长度对比
> **数据**：SUI 金标 16 样本（context=义原层展开，concept=节点层锚点）
> **日期**：2026-08-26

---

## 一、测量设计

**验证目标**：
- P-1④ 结构面：压缩来自起点上移——模型锁定节点层锚点（概念词）后，跳过义原层展开（完整定义）的组合开销
- P-2 结构面：压缩比与层累链深度正相关

**测量**：压缩比 = 义原层展开长度（金标 context 定义）/ 节点层锚点长度（概念词字符数）。概念锚点是提示词锁定的节点表示，定义是未锁定时模型需要自义原层展开的完整表述。

## 三、结论

**P-1④ 结构面成立**：概念锚点（节点层表示，1 字符）比义原层展开（完整定义，10-19 字符）短约 **15 倍**——提示词锁定节点后模型跳过义原层展开的组合开销，压缩来自起点上移而非 token 减少（锚点 token 极少，压缩比远超任何 token 差异）。

**P-2 结构面部分成立**：深/浅二分成立（深层 16.27 > 浅层 12.60，深度效应存在），但三组非严格单调——歧义层（14.33）低于层累层（17.00）。歧义层 context 较短（平均 14.3 字）源于金标歧义样本的定义只捕捉了多义分叉的一面，长度不等于层累丰富度（歧义层义原族数最高，见 E-1）。深度效应在"深 vs 浅"层面确认，逐层单调性受样本与 context 性质限制。

## 四、诚实声明与边界

1. **测量属性**：压缩比为表示层长度比（字符数），是"起点上移节省展开开销"的结构代理，非生成层 token 压缩比（后者需 API 实验）
2. **context 性质**：金标 context 为人工定义句，代表义原层展开的近似——不同样本的定义详略不一，歧义层定义偏短导致非单调
3. **小样本**：16 样本，趋势级证据
4. **判定范围**：P-1④ 结构面成立；P-2 结构面"深 vs 浅"成立、"逐层单调"待更多样本；生成面（实际推理 token 节省）待 API
